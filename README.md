# Student Clinic Record Manager (SCRM)

This is our group project for programming. A simple **C# Console Application** for managing student clinic records. This system allows adding, viewing, searching, editing, deleting, sorting, and filtering student records. All records can also be saved to and loaded from a text file for persistence.

---

# Features

1. Add Record – Enter new student details (name, age, grade, complaint, treatment, date).
2. View Records – Display all existing records.
3. Search Records– Find records by student name.
4. Edit Records – Update student information.
5. Delete Records – Remove a student’s record safely with confirmation.
6. Sort Records – Organize records alphabetically by student name or their surname.
7. Filter Records – Filter based on grade/course.
8. Save to File – Store records in `clinic_records.txt`.
9. Load from File – Automatically loads saved records on program start.

---

## Tech Stack

- Language: C#  
- Framework: .NET 9.0  
- Data Storage: Plain text file (`clinic_records.txt`)
